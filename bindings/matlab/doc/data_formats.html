Sample Formats and Scaling

How MATLAB arrays correspond to device samples

Array shape

RX and TX data always have one column per channel: receive returns an N × numel(dev.RxChannels) complex array, and transmit takes N × numel(dev.TxChannels). With RxChannels = [1 2], column 1 is RX1 and column 2 is RX2. For single-channel transmit, a row vector also works.

For transmit, real arrays are treated as Q = 0. All writes in one TxStream session must be of the same class (single/double, int16, or int8), determined by the first write.

Full scale and dBFS

±1 corresponds to ADC / DAC full scale. A complex tone of amplitude 1 has a power of 0 dBFS; on receive, I or Q reaching ±1 means saturation, so lower RxGain. On transmit, an amplitude of 0.5–0.7 leaves headroom so the peaks of multi-tone or modulated signals are not clipped.

p_dbfs = 10*log10(mean(abs(double(x)).^2));    % average power, dBFS
clipped = any(abs(real(x)) >= 0.999 | abs(imag(x)) >= 0.999);

The host ring buffer stores the USB wire format: 3 bytes per complex sample for 12-bit and 2 bytes for 8-bit, regardless of the type on the MATLAB side.

8-bit mode

IQBits = 8 halves the size of each sample on USB, so dual-channel RX and TX can both reach 61.44 MSPS. The cost is a dynamic range of about 48 dB. It requires RxChannels = TxChannels = [1 2]; you can keep using single output, and int8 is just the most memory-efficient choice.
