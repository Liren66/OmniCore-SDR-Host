样点格式与缩放

MATLAB 数组与设备样点之间的对应关系

数组形状

收发数据都是每通道一列：接收得到 N × numel(dev.RxChannels) 的复数数组，发射输入 N × numel(dev.TxChannels)。RxChannels = [1 2] 时第 1 列是 RX1、第 2 列是 RX2。单通道发射时行向量也可以。

类型

类型接收发射每样点每通道
single（默认）±1 满量程±1 满量程，超出部分限幅（omnicore:TxClipped）；NaN 按 08 字节
double同上同上16 字节
int1612 位样点左对齐：±32768 满量程，低 4 位为 0同样按左对齐解释，低 4 位被忽略4 字节
int8只在 IQBits = 8 时可用，±128只在 IQBits = 8 时可用2 字节

发射时实数数组按 Q = 0 处理。一次 TxStream 会话中的所有写入必须是同一类（single/double、int16 或 int8），由第一次写入决定。

满量程与 dBFS

±1 对应 ADC / DAC 满量程。幅度为 1 的复单音功率为 0 dBFS；接收时 I 或 Q 达到 ±1 说明已经饱和，应降低 RxGain。发射时幅度 0.5–0.7 留出余量，避免多音或调制信号的峰值被限幅。

p_dbfs = 10*log10(mean(abs(double(x)).^2));    % 平均功率，dBFS
clipped = any(abs(real(x)) >= 0.999 | abs(imag(x)) >= 0.999);

主机环形缓冲按 USB 线路格式存储：12 位每复样点 3 字节，8 位 2 字节，与 MATLAB 侧的类型无关。

8 位模式

IQBits = 8 让每个样点在 USB 上只占一半，双通道收发都可以到 61.44 MSPS。代价是动态范围约 48 dB。要求 RxChannels = TxChannels = [1 2]；可以继续用 single 输出，int8 只是最省内存的选择。
