time, timeTicks, setTime, lastPPS

Read and set the device's hardware time

Syntax

t = time(dev)

ticks = timeTicks(dev)

setTime(dev, t)

setTime(dev, t, 'AtNextPPS', true)

[t, ticks] = lastPPS(dev)

Description

t = time(dev)

The device's current hardware time in seconds. Hardware time is a count of the sample clock, 1 tick = 1 sample, t = ticks / SampleRate.

ticks = timeTicks(dev)

Same as above, as a uint64 sample count.

setTime(dev, t)

Sets the hardware time to t seconds immediately.

setTime(dev, t, 'AtNextPPS', true)

Sets the time to t on the next PPS edge of TimeSource: the sample on that edge has time t, and from then on whole-second hardware times fall on PPS edges. TimeSource must not be 'none'.

[t, ticks] = lastPPS(dev)

The hardware time latched on the most recent PPS edge.

Examples

Align to an external PPS, then transmit at a whole second 
dev.ClockSource = 'external';        % 10 MHz reference (optional)
dev.TimeSource = 'external';         % PPS input
setTime(dev, 0, 'AtNextPPS', true);
pause(1.5);
[tp, ticks] = lastPPS(dev)           % about 1 (±1 sample)
transmit(dev, x, 'StartTime', ceil(time(dev)) + 1);   % the PPS edge after next

Tips

  • PPS is not synchronized with the sample clock, so the time latched on PPS has ±1 sample jitter.
  • Changing SampleRate restarts the hardware time; if the time had been set, an omnicore:TimeInvalidated warning is given.
  • The "time has been set" state persists after closing and reopening the device (status(dev).TimeValid).
