time, timeTicks, setTime, lastPPS

读取和设置设备的硬件时间

语法

t = time(dev)

ticks = timeTicks(dev)

setTime(dev, t)

setTime(dev, t, 'AtNextPPS', true)

[t, ticks] = lastPPS(dev)

说明

t = time(dev)

设备当前的硬件时间，秒。硬件时间是采样时钟的计数，1 tick = 1 个样点，t = ticks / SampleRate。

ticks = timeTicks(dev)

同上，uint64 样点数。

setTime(dev, t)

立即把硬件时间设为 t 秒。

setTime(dev, t, 'AtNextPPS', true)

在 TimeSource 的下一个 PPS 沿把时间设为 t：那个沿上的样点时间为 t，此后整秒的硬件时间都落在 PPS 沿上。TimeSource 不能是 'none'。

[t, ticks] = lastPPS(dev)

最近一个 PPS 沿锁存的硬件时间。

示例

与外部 PPS 对齐，然后在整秒定时发射 
dev.ClockSource = 'external';        % 10 MHz 参考（可选）
dev.TimeSource = 'external';         % PPS 输入
setTime(dev, 0, 'AtNextPPS', true);
pause(1.5);
[tp, ticks] = lastPPS(dev)           % 约为 1（±1 样点）
transmit(dev, x, 'StartTime', ceil(time(dev)) + 1);   % 下下个 PPS 沿

提示

  • PPS 与采样时钟不同步，所以 PPS 锁存的时间有 ±1 样点抖动。
  • 改 SampleRate 会让硬件时间重新开始；如果时间设过，给 omnicore:TimeInvalidated 警告。
  • “时间已设定”的状态在关闭再打开设备后仍然保留（status(dev).TimeValid）。
