transmit

Transmit one burst and wait for the device to confirm it was sent

Syntax

transmit(dev, x)

transmit(dev, x, Name, Value)

s = transmit(___)

Description

transmit(dev, x)

Sends x as one burst and returns after the device reports the end of the burst (BurstAck). x is N × numel(dev.TxChannels); for a single channel, a row vector also works.

transmit(dev, x, Name, Value)

Specifies the start hardware time, the timeout, or the buffer size.

s = transmit(___)

Returns the TX event statistics for this burst.

Examples

A tone burst 
dev = omnicore.Device('TxChannels', 1, 'TxFrequency', 2.45e9, 'TxGain', 20);
x = single(0.5 * exp(1j*2*pi*1e6/dev.SampleRate*(0:30719).'));
s = transmit(dev, x);
fprintf('Burst ended at hardware time %.6f s\n', s.AckTime);
Timed burst 
t = time(dev) + 0.5;
s = transmit(dev, x, 'StartTime', t);
(s.AckTime - t) * dev.SampleRate        % burst length plus device pipeline delay, in samples

Input arguments

x single | double | int16 | int8, complex or real
single / double use ±1 full scale; anything beyond is clipped with an omnicore:TxClipped warning; real values are transmitted with Q = 0. int16 is 12-bit samples left-aligned; int8 is only available with IQBits = 8. See Sample Formats and Scaling.

Name-value arguments

'StartTime' seconds
Hardware time of the first sample. If it has already passed, the device reports Late and an omnicore:TxLate warning is given.
'Timeout' seconds, default 1
Maximum time without progress; beyond it, omnicore:TIMEOUT is raised. For a timed burst, the wait automatically includes the delay until StartTime.
'BufferBytes' bytes, default 64 MiB
Host ring buffer size.

Output arguments

s struct
FieldMeaning
UnderflowNumber of times the device ran out of samples while transmitting (RF underflow), with an additional omnicore:TxUnderflow warning
StarvedNumber of times the host queue was empty during the burst. This also appears while a timed burst waits to start, where it is harmless
LateNumber of times the start time had already passed
BurstAckNumber of burst ends confirmed by the device
AckTime, AckTicksHardware time of the burst end (seconds / uint64 samples)
Errors, LastError, DroppedNumber of TX errors reported by the device, the last error, and the number of events dropped when the event queue was full

Tips

  • Each device has only one TX stream: while transmitRepeat or a TxStream is active, transmit raises omnicore:BUSY.
  • For several consecutive timed bursts, or for generating while transmitting, use TxStream so you do not have to wait for confirmation each time.
