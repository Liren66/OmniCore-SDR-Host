transmit

发射一个突发，等待设备确认发完

语法

transmit(dev, x)

transmit(dev, x, Name, Value)

s = transmit(___)

说明

transmit(dev, x)

把 x 作为一个突发发出，设备报告突发结束（BurstAck）后返回。x 为 N × numel(dev.TxChannels)，单通道时行向量也可以。

transmit(dev, x, Name, Value)

指定开始的硬件时间、超时或缓冲大小。

s = transmit(___)

返回这个突发的 TX 事件统计。

示例

一个单音突发 
dev = omnicore.Device('TxChannels', 1, 'TxFrequency', 2.45e9, 'TxGain', 20);
x = single(0.5 * exp(1j*2*pi*1e6/dev.SampleRate*(0:30719).'));
s = transmit(dev, x);
fprintf('突发结束于硬件时间 %.6f s\n', s.AckTime);
定时突发 
t = time(dev) + 0.5;
s = transmit(dev, x, 'StartTime', t);
(s.AckTime - t) * dev.SampleRate        % 突发长度加上设备流水线延迟，样点

输入参数

x single | double | int16 | int8，复数或实数
single / double 按 ±1 满量程，超出部分限幅并给 omnicore:TxClipped 警告；实数按 Q = 0 发射。int16 为 12 位样点左对齐；int8 只在 IQBits = 8 时可用。见样点格式与缩放。

名称-值参数

'StartTime' 秒
第一个样点的硬件时间。已经过去时设备报告 Late，并给 omnicore:TxLate 警告。
'Timeout' 秒，默认 1
没有进展的最长时间，超过报 omnicore:TIMEOUT。定时突发的等待时间自动加上到 StartTime 的延迟。
'BufferBytes' 字节，默认 64 MiB
主机环形缓冲大小。

输出参数

s 结构体
字段含义
Underflow设备发射时样点用完的次数（射频欠流），另有 omnicore:TxUnderflow 警告
Starved突发进行中主机队列为空的次数。定时突发等待开始时也会出现，此时无害
Late开始时间已过的次数
BurstAck设备确认的突发结束次数
AckTime, AckTicks突发结束的硬件时间（秒 / uint64 样点）
Errors, LastError, Dropped设备报告的 TX 错误数、最后一条错误、事件队列满时丢掉的事件数

提示

  • 每台设备只有一个 TX 流：transmitRepeat 或 TxStream 活动时，transmit 报 omnicore:BUSY。
  • 多个连续的定时突发、或边算边发时，用 TxStream，不必每次都等确认。
