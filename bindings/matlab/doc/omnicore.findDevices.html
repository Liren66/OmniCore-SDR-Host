omnicore.findDevices

列出已连接的 OmniCoreSDR 设备

语法

devices = omnicore.findDevices()

说明

devices = omnicore.findDevices()

返回 N × 1 结构体数组，按序列号排序；没有设备时为 0 × 1。已被打开的设备（本程序或其他程序）也会列出。

示例

d = omnicore.findDevices();
for k = 1:numel(d)
    fprintf('%s  %s  固件 %s  USB %d Mbit/s\n', d(k).Serial, d(k).Name, d(k).Firmware, d(k).UsbSpeedMbps);
end
dev = omnicore.Device(d(1).Serial);

输出参数

devices 结构体数组
Serial序列号，用于 omnicore.Device(serial)
Name, Firmware名称、固件版本
UsbDriver, UsbSpeedMbpsUSB 驱动、链路速度
RxChannelCount, TxChannelCount通道数

提示

  • 列表为空时：检查 USB 数据线；Windows 运行 och-driver install 安装驱动；Linux 安装 udev 规则。命令行 och find 给出同样的列表和诊断提示。
