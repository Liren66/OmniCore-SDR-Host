omnicore.findDevices

List connected OmniCoreSDR devices

Syntax

devices = omnicore.findDevices()

Description

devices = omnicore.findDevices()

Returns an N × 1 struct array sorted by serial number; 0 × 1 when there are no devices. Devices already open (in this program or another) are also listed.

Examples

d = omnicore.findDevices();
for k = 1:numel(d)
    fprintf('%s  %s  firmware %s  USB %d Mbit/s\n', d(k).Serial, d(k).Name, d(k).Firmware, d(k).UsbSpeedMbps);
end
dev = omnicore.Device(d(1).Serial);

Output arguments

devices struct array
SerialSerial number, for omnicore.Device(serial)
Name, FirmwareName, firmware version
UsbDriver, UsbSpeedMbpsUSB driver, link speed
RxChannelCount, TxChannelCountNumber of channels

Tips

  • If the list is empty: check the USB data cable; on Windows run och-driver install to install the driver; on Linux install the udev rule. The command-line och find gives the same list with diagnostic hints.
