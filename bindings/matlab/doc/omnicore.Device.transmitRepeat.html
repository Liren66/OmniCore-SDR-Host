transmitRepeat, stopTransmit, isTransmitting

在后台循环发射一段波形

语法

transmitRepeat(dev, x)

transmitRepeat(dev, x, 'BufferBytes', b)

s = stopTransmit(dev)

tf = isTransmitting(dev)

说明

transmitRepeat(dev, x)

立即返回，后台线程不断重复发射 x，直到 stopTransmit 或删除设备对象。x 会被复制，之后可以修改或清除。再次调用会替换波形（先停止再开始）。类型同 transmit。

transmitRepeat(dev, x, 'BufferBytes', b)

指定主机环形缓冲大小。

s = stopTransmit(dev)

停止循环发射，返回开始以来的 TX 事件统计（字段同 transmit）；Underflow 不为 0 说明主机没跟上。没有在发射时返回 []。

tf = isTransmitting(dev)

循环发射进行中为 true。

示例

循环发射单音，同时接收 
dev = omnicore.Device('RxChannels', 1, 'TxChannels', 1, 'TxGain', 20);
fs = dev.SampleRate;
x = single(0.5 * exp(1j*2*pi*1e6/fs*(0:30719).'));   % 整数个周期，首尾相接无跳变
transmitRepeat(dev, x);
y = receive(dev, 1e6);
s = stopTransmit(dev)

提示

  • 波形首尾应能无缝相接（整数个周期），否则每次重复都有相位跳变。
  • 波形太短时会被复制拼接到至少一个 USB 传输长度，对结果没有影响。
  • 循环发射期间 RX 可以正常使用；但按全双工启停规则，TX 运行时 RX 只能开始一次（一次 receive 或一个 RxStream）。
