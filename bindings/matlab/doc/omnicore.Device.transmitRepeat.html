transmitRepeat, stopTransmit, isTransmitting

Transmit a waveform in a background loop

Syntax

transmitRepeat(dev, x)

transmitRepeat(dev, x, 'BufferBytes', b)

s = stopTransmit(dev)

tf = isTransmitting(dev)

Description

transmitRepeat(dev, x)

Returns immediately; a background thread keeps transmitting x repeatedly until stopTransmit or until the device object is deleted. x is copied, so you can modify or clear it afterwards. Calling it again replaces the waveform (stop, then start). Types are the same as for transmit.

transmitRepeat(dev, x, 'BufferBytes', b)

Specifies the host ring buffer size.

s = stopTransmit(dev)

Stops the loop and returns the TX event statistics since it started (same fields as transmit); a non-zero Underflow means the host did not keep up. Returns [] when not transmitting.

tf = isTransmitting(dev)

True while the loop is transmitting.

Examples

Loop a tone while receiving 
dev = omnicore.Device('RxChannels', 1, 'TxChannels', 1, 'TxGain', 20);
fs = dev.SampleRate;
x = single(0.5 * exp(1j*2*pi*1e6/fs*(0:30719).'));   % whole number of periods, joins end to start without a jump
transmitRepeat(dev, x);
y = receive(dev, 1e6);
s = stopTransmit(dev)

Tips

  • The end of the waveform should join its start seamlessly (a whole number of periods); otherwise every repetition has a phase jump.
  • A very short waveform is copied and concatenated to at least one USB transfer length, which does not affect the result.
  • RX can be used normally during looped transmission; but by the full-duplex start/stop rules, while TX is running RX can only be started once (one receive or one RxStream).
