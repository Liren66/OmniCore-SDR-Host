omnicore.doc

在帮助浏览器中打开 OmniCoreSDR 文档

语法

omnicore.doc

omnicore.doc(topic)

file = omnicore.doc(___)

说明

omnicore.doc

打开文档首页。

omnicore.doc(topic)

打开某个类、函数、方法或主题的页面。topic 可以是 'Device'、'omnicore.RxStream'、方法名 'receive'、'setTime'，或主题 'examples'、'errors'、'streaming'、'time'、'formats'、'simulink'，不区分大小写。

file = omnicore.doc(___)

只返回页面文件的完整路径，不打开。

示例

omnicore.doc('receive')
omnicore.doc examples

提示

  • 工具箱文件夹在 MATLAB 路径上时，文档也出现在帮助浏览器首页的“补充软件”中（由工具箱文件夹里的 info.xml 注册）。omnicore.doc 在所有 MATLAB 版本中都能直接打开页面。
