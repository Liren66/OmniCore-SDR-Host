omnicore.doc

Open the OmniCoreSDR documentation in the Help browser

Syntax

omnicore.doc

omnicore.doc(topic)

file = omnicore.doc(___)

Description

omnicore.doc

Opens the documentation start page.

omnicore.doc(topic)

Opens the page for a class, function, method, or topic. topic can be 'Device', 'omnicore.RxStream', a method name such as 'receive' or 'setTime', or a topic: 'examples', 'errors', 'streaming', 'time', 'formats', 'simulink'; case-insensitive.

file = omnicore.doc(___)

Only returns the full path of the page file, without opening it.

Examples

omnicore.doc('receive')
omnicore.doc examples

Tips

  • When the toolbox folder is on the MATLAB path, the documentation also appears under "Supplemental Software" on the Help browser start page (registered by the info.xml in the toolbox folder). omnicore.doc opens the pages directly in every MATLAB release.
