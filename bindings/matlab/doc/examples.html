示例

工具箱 examples 文件夹中的完整程序

先把示例文件夹加到路径：

addpath(fullfile(fileparts(which('omnicore_mex')), 'examples'))

应用示例都有 'Simulate', true 选项：不连设备，用软件模拟的信道运行，便于先看懂流程。每个示例的完整说明用 help 查看，例如 help fm_radio。示例只用 MATLAB 本体，不需要任何工具箱。

自发自收示例默认在 433.92 MHz 用很低的发射功率（fm_loopback 的 TxGain 30 dB、video_link 40 dB，即衰减 59.75 / 49.75 dB）。最好用衰减器把 TX1 连到 RX1（30–60 dB）；使用天线时遵守当地无线电规定。2.4 GHz 空中收发会被 Wi-Fi 帧（几毫秒、比本信号强）打断，video_link 因此大量丢帧，用线缆或 433.92 MHz 可以避开。

应用

fm_radio — 调频广播收音机

收听 88–108 MHz 调频广播（单声道），实时显示射频频谱、复合信号（MPX）频谱和音频波形。演示：偏置调谐与数字混频、多相抽取滤波、鉴相器解调、去加重、连续接收时的实时处理。

fm_radio(98.7e6)                                   % RX1 接 FM 天线，播放 30 s
a = fm_radio(98.7e6, 'Seconds', 10, 'Audio', false);
fm_radio(98.7e6, 'Simulate', true)                 % 两个模拟电台

fm_loopback — FM 自发自收

同一块板上 TX1 在 433.92 MHz 发射调频音频（默认 MATLAB 自带的 handel），RX1 接收、解调并播放；结束后把收到的音频与发出的对齐，给出端到端延迟和音频信噪比。演示：一个循环里全双工收发、TX 余量、TX/RX 本振错开、链路测量。

r = fm_loopback('Seconds', 5);
fprintf('延迟 %.1f ms，SNR %.1f dB\n', 1e3*r.DelaySeconds, r.SnrDb);
fm_loopback('Simulate', true, 'Channel', struct('Loss', 70))

video_link — 数字视频传输

逐帧读取视频（默认 MATLAB 自带的 xylophone.mp4），压缩成 JPEG，用 QPSK 突发从 TX1 发出，在 RX1 解码显示，同时显示星座图、EVM、频偏和吞吐率。演示：根升余弦成形与匹配滤波、Zadoff-Chu 前导同步、频偏估计、导频相位跟踪、校验和、按硬件时间戳定时发射并从 RX 流中截取。一帧要全部比特正确，需要约 15 dB 信噪比。

r = video_link('Seconds', 10);
video_link('Simulate', true)
video_link('Simulate', true, 'Channel', struct('Loss', 64))   % 低信噪比下的丢帧

sdr_scope — 简易示波器与频谱仪

图形界面：I/Q、幅度或相位波形（上升/下降沿触发、电平、时间跨度），平均频谱与峰值保持，右侧控件实时修改中心频率、采样率、增益/AGC、通道。演示：用 receive 反复取新鲜快照、在界面回调中修改设备参数。

sdr_scope
sdr_scope('Frequency', 433.92e6, 'SampleRate', 5e6)
sdr_scope('Simulate', true)                        % 单音 + 周期性线性调频脉冲

基础

文件内容
rx_spectrum.m采集 1e6 样点，画 RX1 频谱
tx_tone_repeat.m后台循环发射单音 10 s
duplex_system_objects.mReceiver + Transmitter 按帧全双工，运行中改频率
timed_burst_loopback.m定时 TX 突发 + 运行中的 RX 流，测回环延迟
simulink_duplex_example.m用脚本搭建并运行 Simulink 全双工模型

示例的结构

应用示例共用 examples/private 中的几个小函数。私有函数只能被 examples 里的文件调用；要在自己的程序里使用，把它们复制到你的文件夹：

sdr_linkRX1/TX1 的统一接口：真实设备（RxStream、TxStream、硬件时间）或模拟信道（延迟、衰减、本振差、噪声、ADC 限幅）
fir_lowpass, fir_decimator, fir_decimate加窗 sinc 低通设计，多相抽取（分块调用，结果与 filter 后抽取完全相同）
fm_transmitter, fm_modulate, fm_receiver, fm_demodulate宽带 FM 调制与解调链
psd_db平均功率谱（dBFS）
audio_sink边收边放：有 Audio Toolbox / DSP System Toolbox 时用 audioDeviceWriter 无缝播放，否则用 audioplayer 分段播放
