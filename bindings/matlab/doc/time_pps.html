硬件时间与 PPS

用设备的样点时钟安排和标记收发

硬件时间

设备有一个 64 位的样点计数器：1 tick = 1 个样点，时间（秒）= ticks / SampleRate。每块接收数据都带有第一个样点的计数值，发射可以指定开始的计数值，所以收发的时间关系精确到样点，与 USB 和 MATLAB 的延迟无关。

操作时间
time(dev), timeTicks(dev)读取当前时间
receive(..., 'StartTime', t), start(rx, 'StartTime', t)在 t 开始接收
meta.Time, meta.TimeTicks每块接收数据第一个样点的时间
transmit(..., 'StartTime', t), write(tx, x, 'StartTime', t)在 t 开始一个突发
s.AckTime, s.AckTicks设备确认突发结束的时间

需要精确到样点时用 ticks（uint64）计算，最后再除以采样率；StartTime 用秒给出时会四舍五入到最近的样点。

定时收发的模式

fs = dev.SampleRate;
t = round((time(dev) + 0.05) * fs);                     % 50 ms 之后，按样点取整
write(tx, burst, 'StartTime', t / fs, 'EndBurst', true);
% 在运行中的 RX 流里，按 meta.TimeTicks 截取 [t, t + numel(burst)) 附近的样点

提前量要够设备收到数据：一般 30–100 ms。来不及时设备报告 Late。示例 video_link 用这个模式逐帧发送；timed_burst_loopback 用它测量 TX→RX 延迟。

PPS 对时

TimeSourcePPS 来自
'none'不用 PPS
'external'外部 PPS 输入（GPS 接收机等）
'internal'板上由参考时钟生成的 PPS
'sync'多板共享的 TRIG 信号
dev.ClockSource = 'external';              % 外部 10 MHz（可选，让采样时钟与参考同源）
dev.TimeSource = 'external';
setTime(dev, 0, 'AtNextPPS', true);        % 下一个 PPS 沿的样点时间为 0
pause(1.5);
[tp, ticks] = lastPPS(dev)                 % 1 秒，±1 样点

之后整秒的硬件时间落在 PPS 沿上，多台设备（各自接同一 PPS 和 10 MHz）按同一个 StartTime 收发即可对齐。

注意

  • PPS 与采样时钟异步，锁存值有 ±1 样点抖动。
  • 改 SampleRate 会让硬件时间重新开始；时间设过时给 omnicore:TimeInvalidated 警告，需要重新 setTime。
  • “时间已设定”的状态在关闭、重新打开设备后保留（status(dev).TimeValid）。
