configure

一次下发多个配置属性

语法

configure(dev, Name, Value, ...)

说明

configure(dev, Name, Value, ...)

把给出的配置属性合并成一次重配置下发。效果与逐个给属性赋值相同，但设备只重配一次：例如同时改采样率和带宽时，正在运行的流只暂停一次。任一值无效时整个请求被拒绝，配置保持不变。

示例

configure(dev, 'SampleRate', 61.44e6, 'RxBandwidth', 56e6, 'TxBandwidth', 56e6);
configure(dev, 'RxFrequency', 915e6, 'RxGainMode', 'manual', 'RxGain', [30 30]);

输入参数

Name, Value
配置属性 SampleRate、RxFrequency、TxFrequency、RxBandwidth、TxBandwidth、RxGain、RxGainMode、TxGain、RxChannels、TxChannels、IQBits，取值见 omnicore.Device 属性。名称区分大小写。

提示

  • 运行中可以改：频率、增益、增益模式、带宽、采样率（采样率改变时流暂停后继续，硬件时间重新开始）。
  • 需要先停掉所有流才能改：RxChannels、TxChannels、IQBits，否则报 omnicore:BUSY。
  • 板级设置（ClockSource、TimeSource 等）不经过 configure，直接给属性赋值。
