configure

Send several configuration properties at once

Syntax

configure(dev, Name, Value, ...)

Description

configure(dev, Name, Value, ...)

Merges the given configuration properties into a single reconfiguration. The effect is the same as assigning the properties one by one, but the device is only reconfigured once: for example, when changing sample rate and bandwidth together, running streams pause only once. If any value is invalid, the whole request is rejected and the configuration stays unchanged.

Examples

configure(dev, 'SampleRate', 61.44e6, 'RxBandwidth', 56e6, 'TxBandwidth', 56e6);
configure(dev, 'RxFrequency', 915e6, 'RxGainMode', 'manual', 'RxGain', [30 30]);

Input arguments

Name, Value
The configuration properties SampleRate, RxFrequency, TxFrequency, RxBandwidth, TxBandwidth, RxGain, RxGainMode, TxGain, RxChannels, TxChannels, IQBits; for values see the omnicore.Device properties. Names are case-sensitive.

Tips

  • Can be changed while running: frequency, gain, gain mode, bandwidth, sample rate (when the sample rate changes, streams pause and then continue, and hardware time restarts).
  • Require stopping all streams first: RxChannels, TxChannels, IQBits; otherwise omnicore:BUSY is raised.
  • Board settings (ClockSource, TimeSource, and so on) do not go through configure; assign the properties directly.
