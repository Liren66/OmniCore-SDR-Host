omnicore.Receiver System object

Receive frames from an OmniCoreSDR; also usable in a Simulink MATLAB System block

Creation

rx = omnicore.Receiver

rx = omnicore.Receiver(Name, Value)

Usage

[y, valid, overflow] = rx()

y
SamplesPerFrame × numel(ChannelMapping) complex frame of type OutputDataType.
valid
False when a full frame was not received within Timeout; the missing part is zero-filled.
overflow
True when samples were dropped before or during this frame (MATLAB did not keep up).

Receiving starts at the first call; release(rx) stops it.

Properties

Except for properties marked "tunable", properties cannot be changed after the first call. Changes to tunable properties take effect on the next call without interrupting reception.

PropertyDefaultDescription
Device[]The omnicore.Device to use (can be shared with other objects and is not closed on release). When empty, the object opens the device itself by SerialNumber and closes it on release
SerialNumber'''' means the only connected device
SamplesPerFrame4096Samples per frame
OutputDataType'single''single', 'double', 'int16', 'int8' (IQBits 8)
ChannelMapping11, 2, or [1 2]; sets the device's RxChannels
SampleRateNaNHz; NaN keeps the device's current value
CenterFrequencyNaNHz, tunable; NaN keeps the device's current value
GainNaNdB, tunable, scalar or per channel; NaN keeps the device's current value
GainMode'''manual', 'fast', 'slow', 'hybrid', tunable; '' keeps the device's current value
BufferBytesNaNHost ring buffer; NaN means 64 MiB
Timeout1Seconds to wait for each block of data

Examples

Receive frame by frame 
rx = omnicore.Receiver('CenterFrequency', 2.45e9, 'SampleRate', 30.72e6, ...
                       'SamplesPerFrame', 65536);
for k = 1:100
    [y, valid, overflow] = rx();
    if k == 50
        rx.CenterFrequency = 2.46e9;    % takes effect on the next frame without interrupting reception
    end
end
release(rx);
Full duplex with Transmitter 
dev = omnicore.Device('RxChannels', 1, 'TxChannels', 1, 'TxFrequency', 2.45e9);
rx = omnicore.Receiver('Device', dev, 'SamplesPerFrame', 30720);
tx = omnicore.Transmitter('Device', dev, 'Gain', 20);
x = single(0.5 * exp(1j*2*pi*(0:30719).'/30.72));
for k = 1:1000
    y = rx();
    tx(x);
end
release(rx); release(tx); delete(dev);

Tips

  • Full duplex: channels cannot change while streams exist, so either pass a Device opened with RxChannels and TxChannels already set to both objects, or call setup(rx); setup(tx, x) before the first call. Simulink initializes all blocks before the simulation starts, so two blocks with the same SerialNumber are enough.
  • The frame after a retune may contain the PLL transient.
  • In Simulink, with SampleRate set, the block's sample time is SamplesPerFrame / SampleRate.
