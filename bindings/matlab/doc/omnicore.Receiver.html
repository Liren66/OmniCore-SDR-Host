omnicore.Receiver System object

按帧从 OmniCoreSDR 接收；也可在 Simulink 的 MATLAB System 模块中使用

创建

rx = omnicore.Receiver

rx = omnicore.Receiver(Name, Value)

用法

[y, valid, overflow] = rx()

y
SamplesPerFrame × numel(ChannelMapping) 复数帧，类型为 OutputDataType。
valid
在 Timeout 内没有收满一帧时为 false，缺少的部分补零。
overflow
本帧之前或之中丢过样点（MATLAB 没跟上）时为 true。

第一次调用时开始接收，release(rx) 停止。

属性

除标明“可调”的属性外，第一次调用后不能修改。可调属性的修改在下一次调用时生效，不中断接收。

属性默认值说明
Device[]要使用的 omnicore.Device（可与其他对象共用，release 时不关闭）。为空时按 SerialNumber 自己打开，release 时关闭
SerialNumber'''' 表示唯一连接的设备
SamplesPerFrame4096每帧样点数
OutputDataType'single''single'、'double'、'int16'、'int8'（IQBits 8）
ChannelMapping11、2 或 [1 2]；设置设备的 RxChannels
SampleRateNaNHz；NaN 保持设备当前值
CenterFrequencyNaNHz，可调；NaN 保持设备当前值
GainNaNdB，可调，标量或每通道；NaN 保持设备当前值
GainMode'''manual'、'fast'、'slow'、'hybrid'，可调；'' 保持设备当前值
BufferBytesNaN主机环形缓冲；NaN 为 64 MiB
Timeout1等待每块数据的秒数

示例

逐帧接收 
rx = omnicore.Receiver('CenterFrequency', 2.45e9, 'SampleRate', 30.72e6, ...
                       'SamplesPerFrame', 65536);
for k = 1:100
    [y, valid, overflow] = rx();
    if k == 50
        rx.CenterFrequency = 2.46e9;    % 下一帧生效，接收不中断
    end
end
release(rx);
与 Transmitter 全双工 
dev = omnicore.Device('RxChannels', 1, 'TxChannels', 1, 'TxFrequency', 2.45e9);
rx = omnicore.Receiver('Device', dev, 'SamplesPerFrame', 30720);
tx = omnicore.Transmitter('Device', dev, 'Gain', 20);
x = single(0.5 * exp(1j*2*pi*(0:30719).'/30.72));
for k = 1:1000
    y = rx();
    tx(x);
end
release(rx); release(tx); delete(dev);

提示

  • 全双工：有流时不能改通道，所以要么把一个打开时就设好 RxChannels 和 TxChannels 的 Device 传给两个对象，要么在第一次调用前先 setup(rx); setup(tx, x)。Simulink 在仿真开始前初始化所有模块，两个模块用同一 SerialNumber 即可。
  • 重新调谐后的那一帧可能含有 PLL 过渡过程。
  • 在 Simulink 中，设定了 SampleRate 时模块的采样时间为 SamplesPerFrame / SampleRate。
