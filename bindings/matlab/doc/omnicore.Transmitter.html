omnicore.Transmitter System object

按帧向 OmniCoreSDR 发射；也可在 Simulink 的 MATLAB System 模块中使用

创建

tx = omnicore.Transmitter

tx = omnicore.Transmitter(Name, Value)

用法

underflow = tx(x)

x
N × numel(ChannelMapping) 的帧：single / double 复数按 ±1 缩放、int16，或 int8（IQBits 8）。各帧连成一个不断开的突发；x 排入队列后立即返回。
underflow
上次调用以来设备样点用完过时为 true：帧的到达速度必须不低于采样率。

release(tx) 发完已排队的样点后停止。

属性

属性默认值说明
Device[]同 Receiver
SerialNumber''同 Receiver
ChannelMapping11、2 或 [1 2]；设置设备的 TxChannels
SampleRateNaNHz；NaN 保持设备当前值
CenterFrequencyNaNHz，可调。改 TX 本振会短暂暂停发射（core 丢弃已排队的样点）
GainNaNdB，0 – 89.75，可调，标量或每通道
Latency0.1第一帧之前先发的零的秒数：设备落后于写入的时间，也就是 MATLAB 可以停顿多久而不欠流
BufferBytesNaN主机环形缓冲；NaN 为 64 MiB
Timeout1等待缓冲空间的秒数

示例

tx = omnicore.Transmitter('CenterFrequency', 2.45e9, 'Gain', 20, 'SampleRate', 30.72e6);
x = single(0.5 * exp(1j*2*pi*(0:30719).'/30.72));     % 1 ms，1 MHz 单音
for k = 1:5000
    if tx(x), disp('underflow'), end
end
release(tx);

只有 Transmitter、没有 Receiver 时，循环不受设备节拍限制：tx(x) 在缓冲满之前立即返回，之后等待设备取走数据。

提示

  • 偶尔欠流时加大 Latency，并避免在循环中画图或打印。
  • 启动 MATLAB 后第一次运行 Simulink 模型时，编译会造成一次较长的停顿，可能报一次欠流；之后的运行没有。
