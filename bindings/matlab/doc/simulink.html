Simulink

在 Simulink 模型中实时收发

添加模块

  1. 从库浏览器 Simulink › User-Defined Functions 拖入 MATLAB System 模块。
  2. System object 名称填 omnicore.Receiver 或 omnicore.Transmitter。
  3. 在模块对话框中设置属性（与 MATLAB 中相同，见 Receiver、Transmitter）。

模块以“解释执行”方式运行，不支持代码生成。Receiver 有三个输出（帧、valid、overflow），Transmitter 有一个输入（帧）和一个输出（underflow）。

时序

  • 设定了 SampleRate 时，Receiver 的采样时间为 SamplesPerFrame / SampleRate；SampleRate 为 NaN 时继承。
  • 仿真由 Receiver 等待每一帧来定速，也就是实时运行；模型的停止时间就是运行的秒数。
  • 只有 Transmitter 的模型不受设备节拍限制，需要用 Receiver 或其他方式定速。

全双工

Simulink 在仿真开始前初始化所有模块，所以 Receiver 和 Transmitter 两个模块使用同一个 SerialNumber（例如都为 ''）即可共用一台设备、同时收发。

示例 simulink_duplex_example.m 用脚本搭建并运行一个全双工模型（Receiver → 增益 → Transmitter）；save_system('omnicore_duplex') 可以保存它。

已知现象

  • 启动 MATLAB 后第一次运行模型时，编译造成一次较长的停顿，Transmitter 可能报一次欠流；之后的运行没有。可加大 Latency。
  • Simulink 不允许字符型参数可调，所以 GainMode 只能在仿真前设定；CenterFrequency 和 Gain 可在仿真中修改。
  • R2024b 对 matlab.system.mixin.Propagates、SampleTime 给出“不推荐使用”提示；为了支持 R2018a 保留。
