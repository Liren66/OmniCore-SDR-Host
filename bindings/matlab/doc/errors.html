错误与警告

omnicore:* 标识符、原因与处理

所有错误和警告的标识符都以 omnicore: 开头。错误消息包含 OmniCore Host 给出的原因。按标识符处理：

try
    [x, meta] = read(rx, n);
catch err
    switch err.identifier
        case 'omnicore:TIMEOUT'
            x = [];                 % 这段时间没有数据
        otherwise
            rethrow(err);
    end
end

错误

标识符含义处理
omnicore:InvalidArgument参数类型、名称或范围错误（在调用设备之前检查）按消息修正参数
omnicore:INVALIDOmniCore Host 拒绝了请求，例如连了多台设备却没给序列号按消息修正
omnicore:BUSY设备被其他程序打开；同一方向已有流；有流时改通道；全双工中一个方向停止后重新开流关闭其他程序；停止已有的流；见全双工启停规则
omnicore:NOT_FOUND没有找到设备，或给的序列号不存在检查连接、驱动、udev 规则；omnicore.findDevices
omnicore:TIMEOUT在 Timeout 内没有数据或没有进展检查定时开始的时间；加大 Timeout
omnicore:IOUSB 传输失败检查数据线、供电、USB 口；重新打开设备
omnicore:STOPPED流已被停止（例如设备在调用期间关闭）重新开始流
omnicore:UNSUPPORTED固件不支持该功能升级固件
omnicore:PROTOCOL, omnicore:BUFFER_SMALL设备通信或内部缓冲问题重新打开设备；持续出现时报告问题
omnicore:InvalidHandle对象对应的设备或流已关闭重新创建对象
omnicore:InterruptedCtrl+C 打断了长调用（需用 OCH_MATLAB_CTRL_C 编译）对象仍可用
omnicore:LibraryNotFoundWindows：MEX 旁边缺 omnicore.dll 或 libusbK.dll使用完整的发布包文件夹
omnicore:OutOfMemoryMATLAB 内存不足减少样点数，或用 int16 输出
omnicore:Internal内部错误报告问题

警告

标识符含义
omnicore:GainLimitedRX 增益超过当前频段上限，已压到上限
omnicore:TxClipped发射样点超出 ±1，已限幅
omnicore:TxLate定时突发的开始时间已经过去
omnicore:TxUnderflow发射过程中设备样点用完
omnicore:TxError设备报告 TX 错误
omnicore:TxNotSent停止时有样点从未发出（不足一个 USB 传输又没有 EndBurst）
omnicore:TimeInvalidated改采样率让设定过的硬件时间失效
omnicore:Transport上次调用以来发生过 USB 传输错误（合并为一条）
omnicore:CloseFailed删除对象时关闭设备或流出错

不需要的警告可以关闭，例如 warning('off', 'omnicore:TxClipped')。

安装问题

现象原因与处理
macOS：MEX 文件“无法打开，因为无法验证开发者”运行 xattr -dr com.apple.quarantine omnicore-matlab
Linux：Invalid MEX-file …GLIBCXX_3.4.xx not foundMATLAB 先加载了自带的旧版 libstdc++。发布包已静态链接 C++ 运行库；自己编译时用发布包的 CMake 设置（-DOCH_STATIC_LIBSTDCXX=ON）
omnicore.findDevices 为空检查 USB 数据线；Windows 安装驱动（och-driver install）；Linux 安装 udev 规则；命令行 och find 会给出诊断
Windows 编译：Supported compiler not detectedMATLAB 不认识新版 Visual Studio，装 Visual Studio 2022 Build Tools 或换更新的 MATLAB
