Getting Started

Install the toolbox and do your first capture and transmission

Installation

Extracting the release package omnicore-matlab-<version>-<platform>.zip (platform win64, maca64, or glnxa64) gives the folder omnicore-matlab, containing the MEX file, the +omnicore package, the OmniCore Host runtime libraries, examples, and this documentation. OmniCore Host does not need to be installed separately.

addpath('<extract-dir>/omnicore-matlab');   % use savepath to keep it permanently
omnicore.version()                         % Library and Header versions should match
omnicore.findDevices()                     % list connected devices
PlatformExtra steps
WindowsThe USB driver needs to be installed once: after installing the OmniCore Host installer, run och-driver install. If you select the MATLAB component in the installer, the same folder is at C:\Program Files\OmniCore Host\matlab.
macOSGatekeeper quarantines zips downloaded by a browser, so the MEX file cannot load. After extracting, run xattr -dr com.apple.quarantine omnicore-matlab once. Requires the Apple Silicon version of MATLAB (R2023b or later).
LinuxInstall the udev rule 60-omnicore.rules so regular users can access the device.
A device can only be opened by one process at a time. While MATLAB holds the device, the och command line, GNU Radio, and other programs cannot open it, and vice versa (raising omnicore:BUSY).

First capture

dev = omnicore.Device('SampleRate', 30.72e6, 'RxFrequency', 2.45e9, 'RxChannels', 1);
[x, meta] = receive(dev, 1e6);       % 1e6 x 1 complex single, full scale ±1
fs = dev.SampleRate;
delete(dev)                          % close the device; clear dev also works

n = 4096;
w = 0.5 - 0.5*cos(2*pi*(0:n-1).'/n);
p = abs(fftshift(fft(double(x(1:n)) .* w))).^2 / sum(w)^2;
plot((-n/2:n/2-1)*fs/n/1e6, 10*log10(p)); xlabel('MHz'); ylabel('dBFS')

On open, the default configuration (30.72 MSPS, 1 GHz, RX channels [1 2], TX off, AGC slow) is applied first, then the constructor arguments are layered on top and sent in one go. After that, every assignment to a configuration property is sent once; to change several parameters at the same time, use configure.

First transmission

First connect TX1 → an attenuator of 30 dB or more → RX1, or put antennas on both ports; set TxGain very low and follow your local radio regulations.

dev = omnicore.Device('TxChannels', 1, 'TxFrequency', 2.45e9, 'TxGain', 20);
x = single(0.5 * exp(1j*2*pi*1e6/dev.SampleRate*(0:99999).'));   % 1 MHz tone
s = transmit(dev, x)                 % one burst; returns after the device confirms it was sent
transmitRepeat(dev, x);              % loop in the background, returns immediately
pause(5);
stopTransmit(dev);
delete(dev)

Next steps

  • Continuous receive: omnicore.RxStream; segmented or timed transmit: omnicore.TxStream.
  • RX and TX together: Streams, Full Duplex, and Dropped Samples.
  • Complete applications: Examples. All the new examples have a 'Simulate', true mode and run without a device.
