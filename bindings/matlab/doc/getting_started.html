入门

安装工具箱，完成第一次采集和发射

安装

发布包 omnicore-matlab-<版本>-<平台>.zip（平台为 win64、maca64、glnxa64）解压后得到文件夹 omnicore-matlab，其中有 MEX 文件、+omnicore 包、OmniCore Host 运行库、示例和本文档。不需要另装 OmniCore Host。

addpath('<解压目录>/omnicore-matlab');   % savepath 可以永久保存
omnicore.version()                      % Library 与 Header 版本应一致
omnicore.findDevices()                  % 列出已连接的设备
平台额外步骤
WindowsUSB 驱动需要安装一次：安装 OmniCore Host 安装包后运行 och-driver install。安装包勾选 MATLAB 组件时，同样的文件夹位于 C:\Program Files\OmniCore Host\matlab。
macOS浏览器下载的 zip 会被 Gatekeeper 隔离，MEX 文件因此无法加载。解压后运行一次 xattr -dr com.apple.quarantine omnicore-matlab。需要 Apple Silicon 版 MATLAB（R2023b 起）。
Linux安装 udev 规则 60-omnicore.rules，普通用户才能访问设备。
设备同一时间只能被一个进程打开。MATLAB 持有设备时，och 命令行、GNU Radio 等程序无法打开它，反之亦然（报 omnicore:BUSY）。

第一次采集

dev = omnicore.Device('SampleRate', 30.72e6, 'RxFrequency', 2.45e9, 'RxChannels', 1);
[x, meta] = receive(dev, 1e6);       % 1e6 x 1 complex single，满量程 ±1
fs = dev.SampleRate;
delete(dev)                          % 关闭设备，也可以 clear dev

n = 4096;
w = 0.5 - 0.5*cos(2*pi*(0:n-1).'/n);
p = abs(fftshift(fft(double(x(1:n)) .* w))).^2 / sum(w)^2;
plot((-n/2:n/2-1)*fs/n/1e6, 10*log10(p)); xlabel('MHz'); ylabel('dBFS')

打开设备时先套用默认配置（30.72 MSPS、1 GHz、RX 通道 [1 2]、TX 关闭、AGC slow），再叠加构造参数，一次下发。之后每次给配置属性赋值都会下发一次；同时改多个参数时用 configure。

第一次发射

先接好 TX1 → 30 dB 以上衰减器 → RX1，或在两个口接天线；把 TxGain 设得很低，并遵守当地无线电规定。

dev = omnicore.Device('TxChannels', 1, 'TxFrequency', 2.45e9, 'TxGain', 20);
x = single(0.5 * exp(1j*2*pi*1e6/dev.SampleRate*(0:99999).'));   % 1 MHz 单音
s = transmit(dev, x)                 % 一个突发，设备确认发完后返回
transmitRepeat(dev, x);              % 后台循环发射，立即返回
pause(5);
stopTransmit(dev);
delete(dev)
