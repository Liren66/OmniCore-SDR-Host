omnicore.Device 句柄类

一台打开的 OmniCoreSDR（AD9361，2RX + 2TX，70 MHz – 6 GHz）

创建

dev = omnicore.Device()

dev = omnicore.Device(serial)

dev = omnicore.Device(___, Name, Value)

dev = omnicore.Device()

打开唯一连接的设备。连了多台时报 omnicore:INVALID（“multiple devices; specify a serial number”），此时按序列号打开；一台都没有时报 omnicore:NOT_FOUND。

dev = omnicore.Device(serial)

打开序列号为 serial 的设备（见 omnicore.findDevices）。

dev = omnicore.Device(___, Name, Value)

打开时同时设定配置属性，例如 omnicore.Device('IQBits', 8)。先套用默认配置（30.72 MSPS、1 GHz、RX [1 2]、TX 关闭、AGC slow），再叠加这些值，一次下发。

设备由本对象独占，直到 delete(dev) 或 clear dev。在同一 MATLAB 会话中再次打开同一台设备，会得到指向同一设备的第二个对象；最后一个对象删除时才关闭设备。退出 MATLAB 时自动关闭所有设备。

属性

配置属性

每次赋值下发一次配置；读回的是设备实际采用的值。超出范围报 omnicore:InvalidArgument，配置不变。

属性值说明
SampleRate2.5e6 – 61.44e6 HzRX、TX 和两个通道共用。时钟链做不到的速率取最近值，读回可得实际值。改采样率会让硬件时间重新开始。
RxFrequency
TxFrequency		70e6 – 6e9 Hz本振频率；两个 RX 通道共用一个本振，TX 同理。运行中可改，改 TX 本振时 core 会丢弃已排队的 TX 样点。
RxBandwidth
TxBandwidth		200e3 – 56e6 Hz模拟滤波器带宽。
RxGaindB，1×2每通道一个值，标量同时设两个。下限 −3；上限随 RX 本振：≤ 1.3 GHz 为 73，≤ 4 GHz 为 71，更高为 62。超过时压到上限，给 omnicore:GainLimited 警告。只在 'manual' 模式下起作用。
RxGainMode'manual' | 'fast' | 'slow' | 'hybrid'AD9361 增益控制模式，默认 'slow'。
TxGaindB，1×2，0 – 89.75步进 0.25。TxGain = 89.75 − 衰减，与 SoapySDR 插件、Pluto 的约定一致。
RxChannels
TxChannels		1 | 2 | [1 2] | []启用的通道，[] 关闭该方向。只能在没有流时修改。
IQBits12 | 8USB 样点位宽。8 位让 USB 带宽翻倍（2T2R 61.44 MSPS），要求 RxChannels = TxChannels = [1 2]。

示例

配置并查看状态 
dev = omnicore.Device();
configure(dev, 'SampleRate', 30.72e6, 'RxFrequency', 2.45e9, 'RxBandwidth', 20e6);
dev.RxGainMode = 'manual';
dev.RxGain = [40 40];
dev                       % 显示当前配置
status(dev)               % 温度、锁定状态、RSSI
8 位模式下的 2T2R 61.44 MSPS 
dev = omnicore.Device('IQBits', 8, 'RxChannels', [1 2], 'TxChannels', [1 2], ...
                      'SampleRate', 61.44e6, 'RxBandwidth', 56e6, 'TxBandwidth', 56e6);
[x, meta] = receive(dev, 1e7, 'OutputDataType', 'int8');   % 1e7 x 2 complex int8
处理“设备被占用” 
try
    dev = omnicore.Device();
catch err
    if strcmp(err.identifier, 'omnicore:BUSY')
        disp('设备被其他程序（och、GNU Radio、另一个 MATLAB）占用');
    else
        rethrow(err);
    end
end

提示

  • 改采样率和带宽等多个参数时用 configure：只重配一次，正在运行的流只暂停一次。
  • 频率和增益可以在流运行时修改（接收数据的 meta.Reconfigured 为 true）；通道和 IQBits 需要先停掉所有流。
  • 对象删除时关闭设备；关闭出错只给 omnicore:CloseFailed 警告。
