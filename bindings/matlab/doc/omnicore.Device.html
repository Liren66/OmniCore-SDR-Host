omnicore.Device handle class

An open OmniCoreSDR (AD9361, 2RX + 2TX, 70 MHz – 6 GHz)

Creation

dev = omnicore.Device()

dev = omnicore.Device(serial)

dev = omnicore.Device(___, Name, Value)

dev = omnicore.Device()

Opens the only connected device. With several connected, raises omnicore:INVALID ("multiple devices; specify a serial number"), in which case open by serial number; with none at all, raises omnicore:NOT_FOUND.

dev = omnicore.Device(serial)

Opens the device with serial number serial (see omnicore.findDevices).

dev = omnicore.Device(___, Name, Value)

Sets configuration properties at open, e.g. omnicore.Device('IQBits', 8). The default configuration (30.72 MSPS, 1 GHz, RX [1 2], TX off, AGC slow) is applied first, then these values are layered on top and sent in one go.

The object holds the device exclusively until delete(dev) or clear dev. Opening the same device again in the same MATLAB session gives a second object pointing to the same device; the device is only closed when the last object is deleted. Exiting MATLAB closes all devices automatically.

Properties

Configuration properties

Each assignment sends one configuration; reading returns the value the device actually uses. Out-of-range values raise omnicore:InvalidArgument, and the configuration stays unchanged.

PropertyValuesDescription
SampleRate2.5e6 – 61.44e6 HzShared by RX, TX, and both channels. Rates the clock chain cannot produce are set to the nearest value; read it back for the actual value. Changing the sample rate restarts the hardware time.
RxFrequency
TxFrequency		70e6 – 6e9 HzLO frequency; both RX channels share one LO, and likewise for TX. Can be changed while running; changing the TX LO makes the core discard queued TX samples.
RxBandwidth

RxGaindB, 1×2One value per channel; a scalar sets both. Lower limit −3; the upper limit depends on the RX LO: 73 at ≤ 1.3 GHz, 71 at ≤ 4 GHz, 62 above. Values above it are clamped, with an omnicore:GainLimited warning. Only takes effect in 'manual' mode.
RxGainMode'manual' | 'fast' | 'slow' | 'hybrid'AD9361 gain control mode, 'slow' by default.
TxGaindB, 1×2, 0 – 89.75Step 0.25. TxGain = 89.75 − attenuation, the same convention as the SoapySDR plugin and Pluto.
RxChannels
TxChannels		1 | 2 | [1 2] | []Enabled channels; [] turns that direction off. Can only be changed while no streams exist.

Examples

Configure and check status 
dev = omnicore.Device();
configure(dev, 'SampleRate', 30.72e6, 'RxFrequency', 2.45e9, 'RxBandwidth', 20e6);
dev.RxGainMode = 'manual';
dev.RxGain = [40 40];
dev                       % show the current configuration
status(dev)               % temperature, lock state, RSSI
2T2R at 61.44 MSPS in 8-bit mode 
dev = omnicore.Device('IQBits', 8, 'RxChannels', [1 2], 'TxChannels', [1 2], ...
                      'SampleRate', 61.44e6, 'RxBandwidth', 56e6, 'TxBandwidth', 56e6);
[x, meta] = receive(dev, 1e7, 'OutputDataType', 'int8');   % 1e7 x 2 complex int8
Handling "device in use" 
try
    dev = omnicore.Device();
catch err
    if strcmp(err.identifier, 'omnicore:BUSY')
        disp('The device is in use by another program (och, GNU Radio, another MATLAB)');
    else
        rethrow(err);
    end
end

Tips

  • Use configure when changing several parameters such as sample rate and bandwidth: it reconfigures only once, so running streams pause only once.
  • Frequency and gain can be changed while streams run (received data has meta.Reconfigured set to true); channels and IQBits require stopping all streams first.
  • The device is closed when the object is deleted; a failure while closing only gives an omnicore:CloseFailed warning.
