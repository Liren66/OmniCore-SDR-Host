OmniCoreSDR for MATLAB › 函数和类

函数和类

按类别列出的全部接口

设备

omnicore.Device打开的 OmniCoreSDR：配置属性、板级设置与全部收发方法
configure一次下发多个配置属性
info, status, events标识信息、实时状态、设备事件
omnicore.findDevices列出已连接的设备
omnicore.version运行库、头文件与 ABI 版本

接收

receive一次采集 N 个样点（可定时开始）
omnicore.RxStream连续接收：start、read、stop
omnicore.Receiver按帧接收的 System object，也是 Simulink 模块

发射

transmit发一个突发并等待设备确认（可定时）
transmitRepeat, stopTransmit, isTransmitting后台循环发射
omnicore.TxStream分段写入与定时突发：write、status、stop
omnicore.Transmitter按帧发射的 System object，也是 Simulink 模块

时间

time, timeTicks, setTime, lastPPS硬件时间（样点计数）与 PPS 对时

帮助

omnicore.doc在帮助浏览器中打开本文档
