omnicore.version

MATLAB 接口使用的 OmniCore Host 版本

语法

v = omnicore.version()

说明

v = omnicore.version()

返回结构体：

Library实际加载的 OmniCore Host 运行库版本
Header编译 MEX 文件时使用的 och.h 版本
AbiC ABI 版本

Library 与 Header 应一致。不一致说明 MEX 文件旁边或系统路径上有另一个版本的运行库。

示例

v = omnicore.version();
assert(strcmp(v.Library, v.Header), 'OmniCore 运行库版本不匹配');

提示

  • 这是检查安装是否正确的第一步：能返回就说明 MEX 文件和运行库都已加载。加载失败时，Windows 报 omnicore:LibraryNotFound，其他平台报 “Invalid MEX-file”，见错误与警告。
