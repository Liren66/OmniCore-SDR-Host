omnicore.version

Version of OmniCore Host used by the MATLAB interface

Syntax

v = omnicore.version()

Description

v = omnicore.version()

Returns a struct:

LibraryVersion of the OmniCore Host runtime library actually loaded
HeaderVersion of och.h used when building the MEX file
AbiC ABI version

Library and Header should match. A mismatch means there is another version of the runtime library next to the MEX file or on the system path.

Examples

v = omnicore.version();
assert(strcmp(v.Library, v.Header), 'OmniCore runtime library version mismatch');

Tips

  • This is the first step in checking that the installation is correct: if it returns, both the MEX file and the runtime library have loaded. If loading fails, Windows raises omnicore:LibraryNotFound and other platforms report "Invalid MEX-file"; see Errors and Warnings.
