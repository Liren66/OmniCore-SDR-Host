receive

Capture N samples at once

Syntax

x = receive(dev, n)

[x, meta] = receive(dev, n)

[x, meta] = receive(___, Name, Value)

Description

x = receive(dev, n)

Captures n samples from each enabled RX channel as one finite-length burst: start, fill, stop. x is an n × numel(dev.RxChannels) complex array with one column per channel, complex single by default, full scale ±1.

[x, meta] = receive(dev, n)

Also returns the hardware time of the first sample and drop information. When samples are dropped, x only contains the samples actually received and has fewer than n rows, with the gap positions in meta.Gaps.

[x, meta] = receive(___, Name, Value)

Specifies the output type, a timed start, the timeout, or the buffer size.

Examples

Capture and plot a spectrum 
dev = omnicore.Device('SampleRate', 30.72e6, 'RxFrequency', 2.45e9, 'RxChannels', 1);
[x, meta] = receive(dev, 1e6);
if meta.Overflow
    warning('%g samples were dropped', sum(meta.Gaps(:, 2)));
end
n = 4096; w = 0.5 - 0.5*cos(2*pi*(0:n-1).'/n);
p = abs(fftshift(fft(double(x(1:n)) .* w))).^2 / sum(w)^2;
plot((-n/2:n/2-1) * dev.SampleRate/n/1e6, 10*log10(p))
Start at a given hardware time 
t0 = time(dev);
[x, meta] = receive(dev, 1e5, 'StartTime', t0 + 0.5);
meta.Time - (t0 + 0.5)        % 0: the first sample is exactly at StartTime
Large captures: save memory with int16 
[x, meta] = receive(dev, 1e8, 'OutputDataType', 'int16');   % 1e8 x 2 takes 0.8 GB
y = single(x) / 32768;                                       % convert to ±1 when needed

Input arguments

dev omnicore.Device
An open device; RxChannels must not be empty.
n positive integer scalar
Number of samples per channel.

Name-value arguments

'OutputDataType' 'single' (default) | 'double' | 'int16' | 'int8'
Output type; see Sample Formats and Scaling. 'int8' is only available with IQBits = 8.
'StartTime' seconds
Hardware time of the first sample (see time). Starts immediately by default. If it has already passed, meta.Late is true.
'Timeout' seconds, default 1
Maximum time to wait for each block of data; with a timed start, the wait for the first block automatically includes the delay until StartTime.
'BufferBytes' bytes, default 64 MiB
Host ring buffer size.

Output arguments

x complex matrix
n × number of channels (fewer rows when samples are dropped).
meta struct
FieldMeaning
TimeHardware time of the first sample, in seconds; NaN when unknown
TimeTicksSame as above, as a uint64 sample count without loss of precision
OverflowWhether samples were dropped
GapsK × 2: [row of the first sample after the drop, number of samples lost]; NaN when the count is unknown. The count is computed from hardware timestamps and is exact
LateFor a timed start, the start time had already passed
ReconfiguredThe device parameters were changed during the capture

Tips

  • Memory per sample per channel: single 8 bytes, double 16, int16 4, int8 2. 1e8 dual-channel samples as single is 1.6 GB.
  • While an RxStream is running, receive raises omnicore:BUSY; in full duplex while TX is running, RX cannot start again after it stops; see Streams, Full Duplex, and Dropped Samples.
  • Each receive creates and stops a new RX stream. That suits repeatedly taking fresh data (e.g. an oscilloscope); for uninterrupted continuous data, use RxStream.
