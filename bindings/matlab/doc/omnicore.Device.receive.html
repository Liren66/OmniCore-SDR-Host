receive

一次采集 N 个样点

语法

x = receive(dev, n)

[x, meta] = receive(dev, n)

[x, meta] = receive(___, Name, Value)

说明

x = receive(dev, n)

从每个启用的 RX 通道采集 n 个样点，作为一个有限长度的突发：开始、采满、停止。x 是 n × numel(dev.RxChannels) 的复数数组，每通道一列，默认 complex single，满量程 ±1。

[x, meta] = receive(dev, n)

同时返回第一个样点的硬件时间和丢样信息。丢样时 x 只含实际收到的样点，行数少于 n，缺口位置在 meta.Gaps 中。

[x, meta] = receive(___, Name, Value)

指定输出类型、定时开始、超时或缓冲大小。

示例

采集并画频谱 
dev = omnicore.Device('SampleRate', 30.72e6, 'RxFrequency', 2.45e9, 'RxChannels', 1);
[x, meta] = receive(dev, 1e6);
if meta.Overflow
    warning('丢了 %g 个样点', sum(meta.Gaps(:, 2)));
end
n = 4096; w = 0.5 - 0.5*cos(2*pi*(0:n-1).'/n);
p = abs(fftshift(fft(double(x(1:n)) .* w))).^2 / sum(w)^2;
plot((-n/2:n/2-1) * dev.SampleRate/n/1e6, 10*log10(p))
在指定硬件时间开始 
t0 = time(dev);
[x, meta] = receive(dev, 1e5, 'StartTime', t0 + 0.5);
meta.Time - (t0 + 0.5)        % 0：第一个样点正好在 StartTime
大数据量：用 int16 节省内存 
[x, meta] = receive(dev, 1e8, 'OutputDataType', 'int16');   % 1e8 x 2 占 0.8 GB
y = single(x) / 32768;                                       % 需要时再转成 ±1

输入参数

dev omnicore.Device
打开的设备，RxChannels 不能为空。
n 正整数标量
每个通道的样点数。

名称-值参数

'OutputDataType' 'single'（默认）| 'double' | 'int16' | 'int8'
输出类型，见样点格式与缩放。'int8' 只在 IQBits = 8 时可用。
'StartTime' 秒
第一个样点的硬件时间（见 time）。默认立即开始。已经过去时 meta.Late 为 true。
'Timeout' 秒，默认 1
等待每一块数据的最长时间；定时开始时，第一块的等待时间自动加上到 StartTime 的延迟。
'BufferBytes' 字节，默认 64 MiB
主机环形缓冲大小。

输出参数

x 复数矩阵
n × 通道数（丢样时行数更少）。
meta 结构体
字段含义
Time第一个样点的硬件时间，秒；未知时为 NaN
TimeTicks同上，uint64 样点数，不损失精度
Overflow是否丢过样点
GapsK × 2：[丢样后第一个样点的行号, 丢失样点数]；数量未知时为 NaN。数量由硬件时间戳算出，是精确值
Late定时开始时，开始时间已经过去
Reconfigured采集期间设备改过参数

提示

  • 内存：每样点每通道 single 8 字节、double 16、int16 4、int8 2。1e8 样点双通道 single 为 1.6 GB。
  • RxStream 运行时 receive 报 omnicore:BUSY；全双工中 TX 正在运行时，RX 停止后不能再开始，见流、全双工与丢样。
  • 每次 receive 都会新建并停止一个 RX 流。需要反复取新鲜数据（例如示波器）时这很合适；需要连续不断的数据时用 RxStream。
