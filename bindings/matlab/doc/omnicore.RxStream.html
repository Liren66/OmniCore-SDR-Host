omnicore.RxStream 句柄类

从 omnicore.Device 连续接收

创建

rx = rxStream(dev)

rx = rxStream(dev, Name, Value)

rx = omnicore.RxStream(dev, Name, Value)

创建流对象，但还不开始接收；调用 start 后设备开始把样点写入主机环形缓冲，read 从中取出。

名称-值参数

'OutputDataType' 'single'（默认）| 'double' | 'int16' | 'int8'
见样点格式与缩放。
'BufferBytes' 字节，默认 64 MiB
主机环形缓冲。MATLAB 没有在读时，样点按线路格式（12 位每复样点 3 字节，8 位 2 字节）在这里等待：64 MiB 在双通道 30.72 MSPS 下约 0.36 s。
'Timeout' 秒，默认 1
read 等待每一块数据的时间，之后也可以改 rx.Timeout。

属性

Device所属设备（只读）
OutputDataType, BufferBytes创建时的设置（只读）
Timeout秒，0 < Timeout ≤ 3600，可修改
IsRunning流是否在运行（只读）

对象函数

start(rx)

开始接收；设备在两次 read 之间持续接收。已在运行时报错。

start(rx, 'StartTime', t)

在硬件时间 t（秒）开始。第一次 read 要等到 t，所以 Timeout 要大于到 t 的延迟。

[x, meta] = read(rx, n)

读每通道 n 个样点，meta 同 receive。在两次 read 之间丢失的样点（缓冲溢出）记在 meta.Gaps 第 1 行。一块数据超过 Timeout 没到时返回已收到的部分；一个样点都没收到则报 omnicore:TIMEOUT。

stop(rx)

停止，未读的样点被丢弃。之后可以再次 start，开始一个新的流（全双工时见启停规则）。

delete(rx)

停止并释放。

示例

连续接收并统计丢样 
dev = omnicore.Device('SampleRate', 15.36e6, 'RxChannels', 1);
rx = rxStream(dev);
start(rx);
lost = 0;
for k = 1:200
    [x, meta] = read(rx, 65536);
    lost = lost + sum(meta.Gaps(:, 2));
    % ... 处理 x ...
end
stop(rx);
fprintf('丢失 %g 个样点\n', lost);
运行中改频率 
start(rx);
x1 = read(rx, 1e5);
dev.RxFrequency = 2.46e9;          % 流不停
[x2, meta] = read(rx, 1e5);         % meta.Reconfigured 为 true

提示

  • 每台设备只有一个 RX 流：流运行时 receive 和第二个流报 omnicore:BUSY。
  • 通道和 IQBits 需要先 stop；频率、增益可在运行中修改；改采样率时流暂停后继续。
  • 处理比实时慢时缓冲会溢出：加大 BufferBytes、减少每块的处理量，或改用 receive 一次采完。
