info, status, events

Device identification, live status, and events

Syntax

s = info(dev)

s = status(dev)

e = events(dev)

Description

s = info(dev)

Identification information, unchanged while the device is open:

Serial, Name, FirmwareSerial number, name, firmware version
UsbDriver, UsbSpeedMbpsUSB driver and link speed (5000 for USB 3.0)
RxChannelCount, TxChannelCountNumber of channels
HardwareTimestampsWhether the firmware provides hardware timestamps
MaxSampleRateMaximum sample rate, Hz
LibraryVersionOmniCore Host runtime library version
s = status(dev)

Live status, read on every call:

Temperature°C; NaN when unavailable
RefLocked, PpsLocked, VcxoLockedReference, PPS, and VCXO lock; false when unknown
TimeValidWhether the hardware time has been set
UsbSpeedMbpsUSB link speed
RxRssiRelative RSSI per channel in dB; NaN when not receiving or with RssiEnable off
e = events(dev)

Retrieves device events since the last call (the most recent 256 are kept) as a struct array in chronological order:

Type'device', 'transport', 'host_overflow', 'rx_gap', 'rx_late', 'rx_sync', 'tx_burst_ack', 'tx_late', 'tx_underflow', 'tx_starved', 'tx_error', 'reconfigured', 'time_invalidated', 'sync_in'
MessageDescription
HwTime, HwTicksHardware time for timed events; NaN / 0 otherwise
CountNumber of merged device events
HostTimeHost monotonic clock, seconds

Examples

i = info(dev); fprintf('%s, firmware %s, USB %d Mbit/s\n', i.Serial, i.Firmware, i.UsbSpeedMbps);
dev.RssiEnable = true;
s = status(dev); s.RxRssi
e = events(dev); {e.Type}

Tips

  • Besides appearing in events, USB transfer errors are also merged into one omnicore:Transport warning when the next call returns.
