info, status, events

设备标识、实时状态和事件

语法

s = info(dev)

s = status(dev)

e = events(dev)

说明

s = info(dev)

标识信息，打开期间不变：

Serial, Name, Firmware序列号、名称、固件版本
UsbDriver, UsbSpeedMbpsUSB 驱动与链路速度（USB 3.0 为 5000）
RxChannelCount, TxChannelCount通道数
HardwareTimestamps固件是否提供硬件时间戳
MaxSampleRate最高采样率，Hz
LibraryVersionOmniCore Host 运行库版本
s = status(dev)

实时状态，每次调用读取一次：

Temperature°C，不可用时为 NaN
RefLocked, PpsLocked, VcxoLocked参考、PPS、VCXO 锁定；未知时为 false
TimeValid硬件时间是否设定过
UsbSpeedMbpsUSB 链路速度
RxRssi每通道相对 RSSI，dB；未接收或 RssiEnable 关闭时为 NaN
e = events(dev)

取出上次调用以来的设备事件（最多保留最近 256 条），按时间先后排列的结构体数组：

Type'device'、'transport'、'host_overflow'、'rx_gap'、'rx_late'、'rx_sync'、'tx_burst_ack'、'tx_late'、'tx_underflow'、'tx_starved'、'tx_error'、'reconfigured'、'time_invalidated'、'sync_in'
Message说明文字
HwTime, HwTicks带时间的事件的硬件时间；其他为 NaN / 0
Count合并的设备事件数
HostTime主机单调时钟，秒

示例

i = info(dev); fprintf('%s，固件 %s，USB %d Mbit/s\n', i.Serial, i.Firmware, i.UsbSpeedMbps);
dev.RssiEnable = true;
s = status(dev); s.RxRssi
e = events(dev); {e.Type}

提示

  • USB 传输错误除了出现在 events 中，还会在下一次调用返回时合并成一条 omnicore:Transport 警告。
