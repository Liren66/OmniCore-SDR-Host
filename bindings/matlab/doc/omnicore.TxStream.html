omnicore.TxStream handle class

Segmented writes and timed bursts

Creation

tx = txStream(dev)

tx = txStream(dev, Name, Value)

tx = omnicore.TxStream(dev, Name, Value)

The device's TxChannels must not be empty. The stream starts at the first write.

Name-value arguments

'BufferBytes' bytes, default 64 MiB
Host ring buffer.
'Timeout' seconds, default 1
Maximum wait when write makes no progress; can be changed later through tx.Timeout.

Properties

Device, BufferBytesRead-only
TimeoutSeconds, can be changed
IsActiveTrue from the first write until stop

Object functions

write(tx, x)

Queues x (one column per TX channel) and returns once all of it has been accepted. Types are the same as for transmit; until stop, all writes must be of the same kind (single/double, int16, or int8).

write(tx, x, 'StartTime', t)

x starts a new burst at hardware time t (seconds).

write(tx, x, 'EndBurst', true)

x ends the current burst (x may be empty). The next write starts a new burst.

s = status(tx)

TX events since the last call, with the same fields as the return value of transmit: Underflow, Starved, Late, BurstAck, AckTime, AckTicks, Errors, LastError, Dropped.

stop(tx)

Sends the queued samples (an unfinished burst is ended with zero padding) and stops; the next write starts again.

Examples

A series of timed bursts 
dev = omnicore.Device('TxChannels', 1, 'TxGain', 20);
fs = dev.SampleRate;
tx = txStream(dev);
x = single(0.5 * exp(1j*2*pi*1e6/fs*(0:19999).'));
t0 = ceil(time(dev)) + 1;
for k = 0:9
    write(tx, x, 'StartTime', t0 + 0.1*k, 'EndBurst', true);   % one burst every 100 ms
end
pause(2);
s = status(tx)          % BurstAck = 10
stop(tx);
A continuous burst generated while transmitting 
tx = txStream(dev);
for k = 1:1000
    write(tx, next_block());       % one unbroken burst: write at no less than the sample rate
end
write(tx, [], 'EndBurst', true);
s = status(tx); stop(tx);

Tips

  • The device only starts transmitting once the queue holds one complete USB transfer (65472 samples single-channel, 32736 dual-channel) or a burst has ended.
  • Keep feeding data within a burst, otherwise status reports Underflow.
  • Each device has only one TX stream: while it is active, transmit, transmitRepeat, and a second stream raise omnicore:BUSY.
  • If you wrote less than one USB transfer without EndBurst, the device never started transmitting; in that case stop gives an omnicore:TxNotSent warning. Write short bursts with 'EndBurst', true.
