omnicore.TxStream 句柄类

分段写入和定时突发

创建

tx = txStream(dev)

tx = txStream(dev, Name, Value)

tx = omnicore.TxStream(dev, Name, Value)

设备的 TxChannels 不能为空。流在第一次 write 时开始。

名称-值参数

'BufferBytes' 字节，默认 64 MiB
主机环形缓冲。
'Timeout' 秒，默认 1
write 没有进展时的最长等待，之后可改 tx.Timeout。

属性

Device, BufferBytes只读
Timeout秒，可修改
IsActive从第一次 write 到 stop 为 true

对象函数

write(tx, x)

把 x（每个 TX 通道一列）排入队列，全部被接受后返回。类型同 transmit；直到 stop 为止，所有写入必须是同一种（single/double、int16 或 int8）。

write(tx, x, 'StartTime', t)

x 在硬件时间 t（秒）开始一个新突发。

write(tx, x, 'EndBurst', true)

x 结束当前突发（x 可以为空）。下一次写入开始新突发。

s = status(tx)

上次调用以来的 TX 事件，字段同 transmit 的返回值：Underflow、Starved、Late、BurstAck、AckTime、AckTicks、Errors、LastError、Dropped。

stop(tx)

把已排队的样点发完（未结束的突发补零结束）并停止；下一次写入重新开始。

示例

一串定时突发 
dev = omnicore.Device('TxChannels', 1, 'TxGain', 20);
fs = dev.SampleRate;
tx = txStream(dev);
x = single(0.5 * exp(1j*2*pi*1e6/fs*(0:19999).'));
t0 = ceil(time(dev)) + 1;
for k = 0:9
    write(tx, x, 'StartTime', t0 + 0.1*k, 'EndBurst', true);   % 每 100 ms 一个突发
end
pause(2);
s = status(tx)          % BurstAck = 10
stop(tx);
边算边发的连续突发 
tx = txStream(dev);
for k = 1:1000
    write(tx, next_block());       % 一个不断开的突发：要以不低于采样率的速度写入
end
write(tx, [], 'EndBurst', true);
s = status(tx); stop(tx);

提示

  • 队列里有一个完整的 USB 传输（单通道 65472、双通道 32736 样点）或突发已结束时，设备才开始发射。
  • 一个突发之内要持续喂数据，否则 status 报 Underflow。
  • 每台设备只有一个 TX 流：活动期间 transmit、transmitRepeat 和第二个流报 omnicore:BUSY。
  • 写入不足一个 USB 传输又没有 EndBurst 时设备从未开始发射；这时 stop 给 omnicore:TxNotSent 警告。短突发请带 'EndBurst', true。
