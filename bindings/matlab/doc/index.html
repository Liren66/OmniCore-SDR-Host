OmniCoreSDR for MATLAB

在 MATLAB 和 Simulink 中使用 OmniCoreSDR：采集、发射、定时收发与全双工

OmniCoreSDR 基于 AD9361：2 路接收、2 路发射，70 MHz – 6 GHz，采样率 2.5 – 61.44 MSPS，带硬件时间戳和 PPS 对时。本工具箱通过 MEX 文件直接调用 OmniCore Host 运行库，不依赖 SoapySDR，也不需要任何 MATLAB 工具箱，支持 MATLAB R2018a 及以后版本。

  • 入门安装、第一次采集、第一次发射。
  • 示例FM 收音机、FM 自发自收、数字视频传输、简易示波器等。
  • 函数和类omnicore.Device、流、System object 的完整参考。

选择接口

需要使用
采一段数据再处理receive
连续接收、边收边处理omnicore.RxStream
发一个突发（可定时）transmit
后台循环发射一段波形transmitRepeat
边算边发、多个定时突发omnicore.TxStream
按帧处理的收发循环，或 Simulinkomnicore.Receiver、omnicore.Transmitter
按硬件时间对齐收发、多次测量硬件时间与 PPS

概念

  • 样点格式与缩放：single / double / int16 / int8，±1 满量程，内存估算。
  • 流、全双工与丢样：每台设备一个 RX 流、一个 TX 流，全双工的启停规则，丢样如何报告。
  • 硬件时间与 PPS：样点计数时钟、定时开始、PPS 对时。
  • Simulink：MATLAB System 模块中的 Receiver / Transmitter。
  • 错误与警告：omnicore:* 标识符及处理方法。
